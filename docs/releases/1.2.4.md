# Sophisticated JEI Index 1.2.4

本次发布提供 Minecraft **1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge** 三个版本，均使用模组版本号 **1.2.4**。

## 更新内容

- 完善 JEI 新旧配方填充接口与数据包协议兼容，覆盖原始包名、迁移到 `legacy` 的包名及带结果回执的新协议。
- 按目标类是否存在启用数据包 Mixin，避免引用不存在的 JEI 包类导致加载崩溃。
- 保留带数量信息的材料操作、新版 JEI 的待处理填充登记与服务端结果回执。
- 调整 1.20.1 服务端数据包处理，将物品槽位解析及库存操作安排在服务端线程。
- 修复 **1.21.1 链接背包兼容**：适配新版 SB 将快照缓存和请求包迁入 Sophisticated Core 的变化，同时保留旧版 SB 接口支持。
- 统一三个 Minecraft 版本的仓库维护结构，各版本仍独立构建。

## 下载与安装

| Minecraft | 加载器 | 文件 |
| --- | --- | --- |
| 1.20.1 | Forge | `sophisticated_jei_index-1.2.4+1.20.1.jar` |
| 1.21.1 | NeoForge | `sophisticated_jei_index-1.2.4+1.21.1.jar` |
| 26.1.2 | NeoForge | `sophisticated_jei_index-1.2.4+26.1.2.jar` |

选择与整合包 Minecraft 版本、加载器匹配的 jar，替换 `mods` 文件夹中的旧版，避免同时加载多个版本。

**本 Release 的 1.21.1 jar 已包含链接背包修复。** 若此前使用过未修复的 1.2.4 或临时 1.2.5 构建，请替换为此处附件。

## 已验证的依赖组合

以下是 2026-10-07 查询并验证的最新组合；表中的 JEI 均为 Beta，SB 与 Core 为正式发布版本。

| Minecraft | JEI | Sophisticated Backpacks | Sophisticated Core |
| --- | --- | --- | --- |
| 1.20.1 | 15.62.0.219 | 1.20.1-3.26.9.2194 | 1.20.1-1.5.6.2378 |
| 1.21.1 | 19.57.0.451 | 1.21.1-3.26.9.2195 | 1.21.1-1.5.7.2381 |
| 26.1.2 | 29.43.0.107 | 26.1.2-3.26.9.2193 | 26.1.2-1.5.7.2377 |

- 最新 26.1.2 JEI 要求 **NeoForge 26.1.2.99+**。
- 更新 SB 时需同时安装符合其要求的 Core；多人游戏客户端与服务端应使用相同的 JEI 版本。
- 同时保留选定旧版 JEI 的兼容支持，最低允许版本分别为 **15.49.0.188 / 19.44.0.403 / 29.20.0.60**。依赖下限不代表所有中间或未来版本都已实测。

## 验证范围

- 三个版本均已构建成功，并通过发布 jar 的接口检查及客户端关键 Mixin 加载检查。
- 1.21.1 在新版及旧版 SB/Core 下通过链接背包功能探针：缺失快照时保持等待、合成快照解析、27 槽背包解析、快照版本更新及请求包构造。
- 1.21.1 的 JEI 接口检查覆盖 19.44.0.403、19.53.0.426、19.57.0.451。
- 尚未覆盖完整的普通/Shift JEI 配方填充、真实联机同步及全部可选终端联动。链接背包探针使用合成快照，不包含真实网络往返。
